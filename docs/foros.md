# Foros de discusión en el aula

**Sí es posible.** Opciones, de menos a más trabajo:

| Opción | Ventajas | Límites |
|---|---|---|
| **A. Foro integrado en el aula (Firestore)** *(recomendada)* | Los estudiantes ya están autenticados; un hilo por módulo; respuestas, “resuelto”, fijar hilos, moderación del docente, notificaciones opcionales por correo (Apps Script). Mismos permisos y reglas de seguridad del aula. | Hay que desarrollarlo (≈ una sesión de trabajo) y moderarlo. |
| **B. GitHub Discussions** | Cero código: se activa en el repositorio. | Exige cuenta de GitHub a cada estudiante; público si el repo es público. |
| **C. Google Chat / Grupo de Google / Classroom** | Inmediato, notificaciones nativas. | Fuera del aula; no queda ligado a cada módulo. |
| **D. Comentarios (Giscus)** | Embebible por página. | Depende de GitHub Discussions (mismo límite que B). |
